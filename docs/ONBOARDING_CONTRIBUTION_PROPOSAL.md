# Separate proposed contribution

Proposed title: `Add an optional read-only AgentOps onboarding kit`

Projects encountering AgentOps need a concrete assessment before adopting guidance.
This candidate adds human and agent entry points, a portable instruction-only skill,
a pending instructions snippet and proportional adoption criteria. Evaluation is
read-only; exact owner approval and authenticated immutable publication precede
documentary changes. Activation remains a separate act.

This proposal is independent of the first evolution PR and the local Update
Discovery experiment. Its base is the current main source. It preserves AGENTOPS/1,
the existing project templates, MIT attribution and all consumer projects. It adds
only exact official research hosts to the public auditor, with rejection tests.

Validation and limitations: see [test results](../AGENTOPS_ONBOARDING_TEST_RESULTS.md)
and [compatibility](../AGENTOPS_ONBOARDING_COMPATIBILITY.md). Fixture assessment is
not a runtime or a demonstration of automatic host discovery. No publication,
installation or consumer adoption has occurred. A real project without a verified
release can receive a contingent proposal but cannot complete adoption under this
profile.

Publication remains NO-GO until the maintainer reviews the exact candidate,
security findings, manifests, source version and release channel. Local technical
readiness does not authorize a push or PR. No commit, tag, release, workflow or
remote operation is proposed as part of executing the kit.
