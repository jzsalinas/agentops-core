# External dependencies and attribution

The AgentOps source and documentation use the root MIT license. External libraries
retain their own licenses. No library code, binary wheels, SDKs, provider actions,
media, fonts, screenshots, logos, source repositories or dependency metadata files
are vendored in this source distribution.

[Dependency inventory](DEPENDENCIES.json) records the direct/transitive Python
distributions declared for the reference tools, reviewed versions, SPDX identifiers,
and package-registry sources. Installation fetches those distributions separately;
it must preserve their original licenses and copyright notices. The project's MIT
notice does not relicense them.

The MIT license text is reproduced as a license grant, not as an attributed prose
excerpt. No externally copied tutorial, workflow, model output report, or historical
operational evidence is included. Examples, fixtures, reference logic, diagrams and
prose are project material and synthetic. Official standards and dependency pages
are references, not copies of their sites or their author metadata.

The inventory covers Python distribution metadata at the stated versions, not a
complete audit of native toolchains or every transitive component inside an upstream
wheel. Native libraries and the interpreter are not redistributed. Changes to pins,
optional extras, vendoring, binaries or images require renewed review. Do not add an
attribution-required resource and then strip notices to satisfy anonymity; exclude
it or obtain a legally approved alternative.

Standards references: [MIT](https://spdx.org/licenses/MIT.html) and
[JSON Schema Draft 2020-12](https://json-schema.org/draft/2020-12/schema).
