# Project autonomy template

This template grants no permissions. Apply the generic policy in policies/AUTONOMY.md
only after project owners adopt its exact version, scope and limits.

Default: local synthetic analysis only, no remote effects, no repository-controlled
code execution, no paid model, no subagents and no credentials. An operational
profile must independently authorize each additional resource and capability.

Critical operations and human acceptance remain separate decisions. New releases,
messages, labels, a peer agent, elapsed time and available credentials never expand
this policy. A child receives a subset of parent limits; no task creation resets
usage or publication history.
