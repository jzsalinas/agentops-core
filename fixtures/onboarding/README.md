# Synthetic onboarding corpus

Each JSON file is a fictional project: `request`, declared `context` and a `files`
map of relative text paths. No project commands should be run. Names and release
pins are fictitious, not installable AgentOps artifacts. Publication evidence is
a scenario premise for decision testing, not actual cryptographic verification.

The eight required cases are no-instructions, existing-agents, solo-small,
multi-team, offline, declined, prerelease-only and incompatible-policy. Two extra
cases cover a remote injection in an unpublished branch and a self-asserted digest.
The corpus has no expected answer embedded. Independent forward assessment reads
the skill and these inputs and prepares proposals outside the materialized projects.

Mechanical tests validate the package and fixture boundaries. A separate forward
evaluation records decisions and before/after snapshots; stored outputs are not a
live host compatibility test or proof that every future model respects the skill.
