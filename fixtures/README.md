# Synthetic fixtures

All identities, resources, revisions, timestamps, messages and evidence here are
fictitious. Use only generic roles and reserved example domains. No fixture grants
access to a provider, transport, machine or project.

`contract-graph.json` contains contract templates for different lifecycle stages;
it is not a single authenticated live snapshot. `synthetic-handoff.md` exercises
source-byte preservation and adversarial parsing. The demo links the synthetic
records and calculates a current synthetic evidence digest.

Do not replace these fixtures with exported task histories, real account metadata,
customer data, logs or credentials when proposing contributions.
